# Bullet Journal

Webapp voor een bullet journal met Supabase-opslag. Eén bestand: `index.html`.

## Gebruiken
1. Publiceer de repo met GitHub Pages (Settings → Pages → branch `main`, map `/`).
2. Open de pagina, kies "Nog geen account? Maak er een" en registreer met e-mail + wachtwoord.
3. Bevestig je e-mail als Supabase daarom vraagt, en log in.

## Installeren als app (PWA)
- **iPhone/iPad (Safari):** Deel → Zet op beginscherm.
- **Android/Chrome:** menu → App installeren.
- **Werk-pc (Edge/Chrome):** installeer-icoon in de adresbalk, of gewoon een bladwijzer; er is niets te installeren nodig.

De app-schil werkt ook offline; je regels worden wel altijd live in Supabase opgeslagen.

## Dagelijks ritme
- Ochtend: dag openen, taken erbij zetten, max. 3 echt belangrijke met `*`.
- Avond: afvinken (tik op de bullet). Wat openstaat: `>` doorschuiven, `<` inplannen of annuleren (via `⋯`).
- Eens per maand: tabblad **Opruimen** doorlopen en de nieuwe maand starten.

## Invoer
